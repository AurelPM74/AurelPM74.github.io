summary: Optimizing the linear layer of ASCON and other reversible linear quantum circuits.
abstract: In order to evaluate the quantum security level of symmetric cryptographic systems one needs to estimate the quantum resources needed by an attack
  using Grover algorithm. The cost of such attacks depends directly on the resources needed to create a quantum circuit implementing the encryption itself.
  Therefore creating an optimized quantum circuit implementing a cryptographic system leads to more accurate post-quantum security evaluations of the system.
  We will present several modification of existing algorithms that we used to create efficient quantum oracles for the ASCON linear layer. These methods
  will not particularly tailored for ASCON and can also be used to create any kind of optimized quantum linear reversible circuits.
